# Laboratório de Algoritmos, Lógica e Full-Stack

**Idioma / Language:** [English](./en.md) | Português (Brasil) | [Página inicial do repositório](../README.md)

> **Espaço pessoal de prática em resolução de problemas, arquitetura de software e desenvolvimento web full-stack.**

Este repositório documenta minha jornada de programação e minhas soluções para diferentes desafios. O objetivo principal é conectar a **otimização da lógica de back-end** ao **desenvolvimento de interfaces front-end**, enquanto desenvolvo minhas habilidades como engenheiro de software full-stack.

## Estrutura do repositório

Os projetos estão organizados por tecnologia:

### Back-end e lógica principal

* **[`Python.pratices/`](../Python.pratices/)** - Scripts, automações, algoritmos e exercícios de lógica de programação.

### Front-end e desenvolvimento web

* **[`frontend/`](../frontend/)** - Experimentos com HTML, CSS e interfaces.

### Banco de dados e modelagem de dados

* **[`Database/`](../Database/)** - Scripts de banco de dados, lógica relacional, consultas e estruturas de modelagem.

## Objetivo

O objetivo é aperfeiçoar o raciocínio algorítmico, fortalecer os fundamentos da ciência da computação e preparar-me para avaliações técnicas e aplicações reais de desenvolvimento full-stack no mercado global.

## Fontes e plataformas

Os exercícios e exemplos de código são inspirados em:

* **Programação competitiva:** Plataformas como [Beecrowd](https://www.beecrowd.com.br/) e [LeetCode](https://leetcode.com/).
* **Projetos acadêmicos e práticos:** Exercícios universitários e projetos web independentes.
