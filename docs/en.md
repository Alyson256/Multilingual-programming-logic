**Language / Idioma:** English | [Português (Brasil)](./pt-br.md) | [Repository home](../README.md)

This repository documents my coding journey and solutions to different challenges. Its main goal is to connect back-end logic optimization with front-end interface design while developing full-stack software engineering skills.

## Repository structure

Projects are organized by technology:

* **[`Python.pratices/`](../Python.pratices/)** - Scripting, automation, algorithms, and programming-logic exercises.

### Front-end and web development

* **[`frontend/`](../frontend/)** - HTML, CSS, and interface experiments.

### Database and data modeling

* **[`Database/`](../Database/)** - SQL scripts, relational logic, queries, and data modeling.

## Goal

The goal is to improve algorithmic thinking, strengthen computer science fundamentals, and prepare for technical assessments and real-world full-stack applications.
